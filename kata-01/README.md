# Kata 1: Reversed Strings

## Instruções

Complete the solution so that it reverses the string passed into it.

```
'world'  =>  'dlrow'
'word'   =>  'drow'
```

## Solução

O código está em [`Kata.java`](Kata.java). O método `solution` percorre a string do último caractere até o primeiro e monta uma nova string nessa ordem.

## Como executar

```bash
java Kata.java
java Kata.java teste
```

Sem argumentos, o programa roda os dois exemplos do enunciado. Com argumentos, inverte cada um deles.
