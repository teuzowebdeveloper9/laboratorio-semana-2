Resolução dos katas da semana 2 de Engenharia de Software.

## Estrutura

Cada kata tem a própria pasta, com as instruções e o código da solução.

```
laboratorio-semana-2/
├── README.md
├── .gitignore
├── kata-01/
│   ├── README.md
│   └── Kata.java
└── kata-02/
    ├── README.md
    └── Game.java
```

## Como executar

É preciso ter o JDK 11 ou mais novo instalado.

```bash
cd kata-01
java Kata.java

cd ../kata-02
java Game.java
```

## Fluxo de trabalho

- Cada kata tem uma tarefa no Jira e uma branch `feature/kata-XX`.
- Os commits seguem `tipo(escopo): Assunto`, em inglês, com assunto no imperativo e sem ponto final.
- O código entra na `main` por pull request, depois da revisão de um colega.
